# Milestone 5 - SEO and Local Search Optimization

Goal
- Maximize local SEO and overall search visibility for the restaurant.

Scope
- Technical SEO (metadata, structured data, sitemap, robots).
- Local SEO (NAP consistency, LocalBusiness schema, location signals).
- Performance and accessibility improvements that impact SEO.

Key Tasks
- Replace default meta tags with brand-specific titles/descriptions.
- Add Open Graph and Twitter image tags using brand assets.
- Add JSON-LD schema for LocalBusiness/Restaurant:
  - Name, address, phone, hours, menu URL, geo, sameAs links.
- Generate sitemap.xml and update robots.txt.
- Ensure canonical URLs are correct on all pages.
- Optimize images (next/image, sizes, lazy loading).
- Improve heading hierarchy and accessible labels (helps SEO).
- Add a dedicated location section with embedded map and full address.

Acceptance Criteria
- Pages pass basic SEO checks (titles, descriptions, canonical, OG tags).
- LocalBusiness schema validates in Google Rich Results Test.
- Sitemap is generated and linked in robots.txt.
- Lighthouse SEO score improves compared to current baseline.
